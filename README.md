## Travel Made Easy

<br/>

Wayliths brings a convenient, configurable teleportation network to your Minecraft server in a format that is instantly recognized by long-time modded Minecraft players. Create custom destinations, travel fluidly across the network, share locations with others, and instantly return to your respawn points.

## Your Destinations, Your Rules

<br/>

Choose precisely how other players can interact with each destination on your server.

<br/>

| **PRIVATE** | **GLOBAL** | **SERVER** |
| :---: | :---: | :---: |
| Keep a Waylith for yourself, completely hidden from other players' Waylith networks | Allow other players on the server to see and travel to your public Waylith, owned by you | Admins can designate global community Wayliths managed under server ownership |

<br/>

## Commands

<br/>

| Command | Description |
| :--- | :--- |
| `/wayliths` | Displays the plugin command usage guide |
| `/wayliths reload` | Reloads plugin and all associated files |
| `/wayliths give <item> [player]` | Gives custom items to yourself or a target player |

<br/>

## Permissions

<br/>

| Permission Node | Description |
| :--- | :--- |
| `wayliths.admin` | Grants full management access, including reloads and item distribution commands. Default: OP. |
| `wayliths.limit.*` | Allows an unlimited number of Waylith block placements. Default: OP. |
| `wayliths.limit.<amount>` | Sets a custom placement cap per player, such as `wayliths.limit.5`. |
| `wayliths.visibility.server` | Allows players to configure editable Waylith destinations with Server ownership status. |
